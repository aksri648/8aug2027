Architecture & System Specification

SaaS Agentic Development Platform

An end-to-end multi-agent software engineering system leveraging Go microservices, React 19, Daytona Cloud Sandboxes, Redis Task Queues, and Azure Infrastructure Provisioning.

Go 1.22 (REST + WS) React 19 + Vite Daytona Sandboxes Redis (LPUSH/BRPOP + PubSub) GORM (Postgres/SQLite) Azure ARM REST SDK vLLM & NVIDIA NIM

2. Multi-Agent Execution & Routing Workflow

Intent Classification & Agent Routing Sequence Sequence Diagram

When a user sends a prompt or selects a task in the Wizard, the Master Agent inspects the user intent, dispatches the task to the dedicated sub-agent, streams progress over WebSocket, and updates the Daytona Cloud Sandbox.

3. Async Job Queue & Real-Time Event Dispatch

Task Queue & Event Pub/Sub Architecture

The platform supports high-throughput execution with double-buffered fallbacks: a Redis-backed queue (`queue:agent_jobs`) with an in-memory channel fallback when Redis is absent.

6. Codebase Audit & Discovered Issues Report

Audit Summary & Fix Verification

A comprehensive static analysis and runtime audit was conducted across Go backend services and React frontend code. Below are the cataloged defects and their applied resolutions:

1. Redis Queue Consumer Bypass Resolved
queue.go: When Redis server was connected, EnqueueJob pushed to Redis queue:agent_jobs, but DequeueJobs only read from internal Go channel.
Fix Applied: Added a background BRPop worker loop in NewRedisQueue to continuously pop jobs from Redis list into the processing channel.
2. Discarded Job Payload Parameters Resolved
cmd/worker/main.go: Worker processing loop initialized an empty payload map and ignored job.Payload json byte array.
Fix Applied: Added json.Unmarshal(job.Payload, &payload) so agent task options (tech stack, prompt, repo URL) pass into agents correctly.
3. Missing Package Import in Code Generator Resolved
appdeveloper.go: Generated /cmd/api/main.go template used time.Now() in /healthz handler, but omitted "time" in import block.
Fix Applied: Updated code template header in AppDeveloperAgent to include "time" package import.
4. Static Controls in Chat Panel Resolved
ChatPanel.jsx: Top bar buttons (Sidebar Toggle, Task Execution Wizard, Config Setup, Favorite Star) were unhandled non-interactive elements.
Fix Applied: Wired event callbacks to open TaskWizardModal, ConfigModal, LivePreviewModal, and state toggles.
